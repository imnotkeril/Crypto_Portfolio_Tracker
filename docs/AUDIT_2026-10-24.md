## 3. Проблемы по важности

**Medium**
1. `streamlit run` по умолчанию биндится на `0.0.0.0` (в логе Network/External URL), аутентификации нет. Приложение показывает и пишет финансовые данные в SQLite: любой в сети может читать и удалять транзакции. Фикс: запускать `streamlit run main.py --server.address 127.0.0.1` (или `.streamlit/config.toml`; сейчас `.streamlit/` в .gitignore, так что нужно убрать из ignore, чтобы конфиг жил в репо). Если нужен доступ из сети: reverse proxy с auth.
2. Работа последнего этапа (13 файлов) не закоммичена, единственная копия на диске. Бэкапа нет, `data/portfolio.db` тоже вне git. Фикс: закоммитить на `main` (решение владельца) и сделать бэкап БД.
3. Тестов нет, расчётная логика (`get_current_portfolio`, `portfolio_calculator`, `metrics`, бэктесты) без проверки. Деньги считаются; рекомендую минимум юнит-тесты на портфель и метрики.
4. Бэктест молча подменяет реальные данные синтетическими (`utils/backtest_data.py:55-56, 75-76, 81-82, 102-105`: любой сбой Binance → synthetic, а funding → константа 0.0001). Пользователь может увидеть «результаты» на выдуманных данных, не зная об этом. Фикс: явная пометка в UI, откуда данные.

**Low**
5. `utils/database.py:69-71, 113-115`: миграция с `except Exception: pass`, при сбое тихо пропускает; `DROP TABLE funding_rates` в `init_database()` при старом столбце `amount` без бэкапа (данные копируются через `INSERT OR IGNORE`, при дубликатах теряются). Риск только для старых БД.
6. `pages/guide.py`: скопированный чат-ответ: заголовок «ТЕПЕРЬ ГАЙД СДЕЛАЙ», картинка-логотип с `r2cdn.perplexity.ai` (внешний запрос с каждого открытия страницы, утечка IP/реферера стороннему хосту). Фикс: убрать картинку и заголовок.
7. `pages/*.py`: повторный `st.set_page_config` в каждой странице (допустимо), 24 использования устаревшего `use_container_width` (ворнинги, в будущих версиях Streamlit сломается). Фикс: `width='stretch'`.
8. Зависимости не запинены (`>=`), нет lockfile; при ломающем релизе pandas/ccxt приложение может сломаться. Фикс: `pip freeze`/uv lock.
9. `README`: «Python 3.8+», pandas 3 требует ≥3.11. Указать 3.11+. (Не менял: версию, с которой реально работает, не прогонял для каждой версии.)
10. Дубли скриптов: `populate_funding.py` (корень) и `scripts/auto_populate_funding.py` почти идентичны. Мёртвый код (`F841` в `price_fetcher.py:246`).
11. Файл `.cursor/debug.log` с отладочным выводом (игнорируется git, секретов нет).
